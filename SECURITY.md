# Security Policy

## Supported versions

Security fixes are made against the current `master` branch and the latest
published release when practical.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security-advisory reporting feature for this repository. If that feature is not
available, open a minimal issue requesting a private contact channel without
including exploit details.

Please include affected paths, reproduction steps, impact, and any relevant
hardware or firmware version. Do not include secrets, private recordings, or
third-party personal data.

The steward will acknowledge reports within seven days and coordinate a fix or
public disclosure timeline with the reporter.
