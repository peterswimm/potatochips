# Governance

## Stewardship

Peter Swimm is the current project steward. The steward is accountable for
release approval, license-boundary decisions, public provenance records, and
handling security reports.

## Decision record

Material decisions belong in issues, pull requests, release notes, or the
provenance records. The record should state intent, source material, affected
people, constraints, and the decision made.

## Attribution and plurality

Upstream authorship remains visible. Contributors may challenge an inaccurate
attribution, license classification, or AI disclosure through an issue or pull
request. The steward must correct substantiated records rather than erase
history.

## Succession

If the current steward becomes unavailable, a successor may be designated in a
signed release note or a public GitHub issue. The successor inherits stewardship
responsibilities, not ownership of upstream work.
