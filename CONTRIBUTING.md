# Contributing

Potato Chips: Spelwork Provenance Edition accepts contributions that preserve
upstream attribution, license clarity, and reproducible behavior.

## Before opening a pull request

1. Open an issue for material changes so intent and affected stakeholders are
   visible before implementation.
2. Keep upstream notices and file-level copyright statements intact.
3. State the license of every new dependency, sample, asset, generated file,
   and contributor-supplied material.
4. Update `PROVENANCE.md`, `THIRD_PARTY.md`, `sbom.spdx.json`, or
   `AI-NUTRITION.md` whenever the change affects them.
5. Disclose material AI assistance by system, role, path scope, validation, and
   accountable human. Do not state or imply model-training-data facts you cannot
   verify.
6. Run the relevant Rack, DSP, and/or disting NT checks and report the commands
   and results in the pull request.

## Contribution license

By submitting a contribution, you certify that you have the right to submit it
and license it under GPL-3.0-or-later, unless the maintainer explicitly accepts
a separately identified compatible license. Do not submit inherited artwork or
other material that you are not authorized to redistribute or adapt.

## Review

The steward reviews changes for behavior, provenance, license boundaries, and
release impact. Passing automation does not replace maintainer approval.
